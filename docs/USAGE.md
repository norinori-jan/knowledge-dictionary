# 使い方ガイド

## 1. 考え方

- 「AIに聞いたこと」を、あとで使える**項目**として残します。
- 1つの項目（例：JWT）に、Q&A（質問と回答）が何件もぶら下がります。
- AIの言ったことと、**自分が決めたこと・分かったこと**は、別の欄に分けて残します。

## 2. Q&Aを足す

1. 画面下の **＋ Q&Aを足す** を押す。
2. AIの質問をコピー → **質問** 欄の「📋 貼り付け」。
3. AIの回答をコピー → **回答** 欄の「📋 貼り付け」。
   - 貼り付けが効かないときは、欄を長押しして貼り付けます。
4. **見出し語**を入れる（例：JWT）。空なら、質問の1行目になります。
   - すでにある見出し語を入れると、「既存の項目に足されます」と出て、一言・タグ・関連用語が自動で入ります。
5. 必要なら、一言説明・自分の判断・タグ・関連用語・ソースを入れる。
6. 右上の **保存**。

### タグの自動抽出
- 質問と回答を入れると、**タグと関連用語が自動で入ります**（端末の中だけで計算。AIも課金も使いません）。
- 拾うもの：`コード`・**太字**・「かぎかっこ」・見出し・英字の名前・カタカナ・すでに使っているタグ。辞書にすでにある見出し語は、関連用語に入ります。
- いらないタグは、下のタグを押して外します。手で触ると、以後は自動で戻しません。
- 🤖AIに聞く で「そのまま保存」したときも、自動で付きます。
- すでにある項目には、⚙︎ の「🏷 タグのない項目に、自動でタグを付ける」で一括して付けられます。
- タグは、押すとそのタグの項目だけに絞り込めます（一覧のタグ・項目画面のタグ）。項目画面の「タグでつながる項目」からは、同じタグの項目に飛べます。

### タグ・関連用語を、その場で選ぶ／作る
- **タグ**：入力欄の下に、すでに使っているタグが並びます。押すと付け外しできます（✓＝付いている）。
- **関連用語**：入力欄の下に、📖（項目がある）と、点線の「＋ ○○ を項目にする」（まだ無い）が並びます。点線を押すと、その場で項目ができます（中身はあとで書けます）。
- **🔗 既存の項目から選ぶ／新しい語を足す**：項目を探して、関連用語に足せます。
- 項目の「編集」画面でも、同じように使えます。

### 保存前の確認（似ている項目）
質問を書くと、すでにある項目に似ているときは、黄色い枠で知らせます。
- **見る**：その項目を開く
- **ここに足す**：見出し語をその項目に合わせる

### ✨ AI整理（任意）
質問と回答を入れて **AI整理** を押すと、見出し語・一言・タグ・関連用語の**候補**が出ます。
- 確認が出ます。質問と回答だけがAIに送られます（**自分の判断は送りません**。秘密らしい行は除きます）。
- 候補は、押したものだけ入ります。**すべて採用**で、一度に入ります。
- 使うには、設定で接続（エンドポイント・トークン）が必要です。quick-ref と同じ設定です。
  同じ端末の同じブラウザで quick-ref を設定済みなら、自動で借ります。

## 2b. 🤖 AIに聞く（アプリから直接）

1. 画面下の **🤖 AIに聞く** を押し、質問を書いて送る。
2. 似た自分の項目があれば「参考にする」チップで、**以前の自分の整理**を一緒に送れます。
3. 答えが出たら **そのまま保存**（質問の1行目が見出し語。1つだけ参考にした項目があれば、そこに足す）か、**整理して保存**（見出し語・タグを決めてから）。
- **費用**：APIのトークンを使います。ChatGPT・Claudeの月額プランとは**別枠**です。画面に今日の回数・概算文字数が出ます。上限は ⚙︎ で変更（初期30回/日）。
- 秘密らしい行は、送る前に除きます（確認が出ます）。
- 「日本語で、結論から簡潔に」などの共通指示は、⚙︎ で変えられます。

## 2g. 🗄 書庫（タグから、棚を自動で作る。AIなし・無料）

画面上の 🗄 から開きます。**タグが付いた項目を、自動で「棚」に集めます。** 端末の中だけで計算するので、トークンは使いません。

- **棚＝タグ。** 棚には、件数・未理解の数・理解済みの進み具合が出ます。押すと開いて、項目が並びます。
- **区画別：** よく一緒に付くタグ（例：認証とWeb）を、自動で同じ「区画」にまとめます。1項目にしか付いていないタグは「ひとつだけの棚」に。ほかに「多い順」「名前順」「新しい順」で並べ替えできます。
- **しぼり込み：** 棚の名前や項目名で探せます。
- **タグなし：** 棚に入っていない項目が出ます。「🏷 自動でタグを付ける」で、中身から自動でタグを付けられます（AIなし）。
- **整理（見返しやすくするために）：**
  - **整理のおすすめ：** 名前が似ている棚（例：認証と認証s）、同じ項目に付いている棚を見つけて、ワンタップで統合できます。
  - 棚の **✏️ 名前を変える**（既存の棚名にすると統合）／ **🔀 別の棚に統合** ／ **棚をなくす**（項目は消えず、タグだけ外れる）。全項目のタグにまとめて反映されます。
  - **一覧で見る**（検索に飛ぶ）／ **▶ この棚を復習**。

## 2f. 📚 体系・学習（回して、知識を体系にする）

画面上の 📚 から開きます。**集める → 整える → 体系にする → 復習する → また集める** を、1画面で回します。「次はこれ」の印が、いま一番やることを教えます。

- **① 集める：** quick-ref の新しいAI Q&Aを取り込む。
- **② 整える：** タグのない項目に自動でタグ／統合できそうな項目を見る。
- **③ 体系にする：** 分野のない項目を、AIが **分野（例：Web/認証）・レベル（基礎／応用／発展）・前提（先に分かっているべき項目）** に整理した候補を出します。確認して「すべて採用」。AI は項目数÷40回ぶん使います（実行前に確認が出ます）。あとで項目の「編集」で手直しできます。
- **④ 復習する：** 前提が分かっている・基礎のものから順に、1問ずつ。結果で **次に出る時期** が決まります（理解済み＝3日→7日→14日→30日と延びる／理解中＝1日後／未理解＝すぐ）。時期が来ると、理解済みでもまた出ます。
- **知識の体系：** 分野ごとに、理解済みの進み具合と項目が並びます。前提が未理解の項目には ⚠️ が出ます。「▶ この分野を復習」で、その分野だけ復習できます。
- 学習ログ（今日の問数・連続日数・合計）は端末の中だけに残ります。

## 2d. 🧠 辞書AI（自分の辞書を材料にするAI）

画面上の 🧠 から開きます。**すべて、APIのトークンを使います**（月額プランとは別枠。上限・使用量は画面に出ます）。

- **辞書に聞く：** 質問すると、辞書の中から（材料が少ないときは、AIが辞書の語彙から言い換えを選んで探し直します。少量のトークンを使います。このとき質問と辞書の語彙＝見出し語・タグだけが送られます）関係する項目・Q&A・自分の判断を探し、それだけを材料にAIが答えます。根拠の項目は `[[リンク]]` で示され、押すと開きます。関係する項目が無いときはAIに送りません。「📌 この答えを項目として残す」で、考え方の項目にできます。
- **復習：** 未理解の項目から1問出し、自分の言葉で答えると、辞書の内容と照らして採点します。結果を見て理解度を決めます（AIのおすすめに印）。
- **知識の穴（無料）：** まだ項目がない言葉／未理解なのによく参照される項目／どことも結びつかない項目を、端末の中だけで一覧にします。
- **項目画面の「🔗 AIでつながりを探す」：** ほかの項目との関連と、足りなそうな知識を提案します。押したものだけ反映されます。
- **保存時のAI整理（任意）：** ⚙︎ でオンにすると、Q&Aを保存したとき、空欄の一言・種類・タグ・関連用語をAIが埋めます。入力済みの内容や見出し語は変えません。保存のたびにAPIを1回使います。

## 2e. 項目の統合（同じ意味の項目を1つに）

- 項目画面の **🔀 ほかの項目と統合する** → 相手を選ぶ。相手は、この項目に吸収されます。
- 相手のQ&Aはこの項目に移り、タグ・関連用語・自分の理解もまとまります。相手の見出し語は **別名** になり、その語の `[[リンク]]` も検索も、この項目に届きます。
- 🧠 →「知識の穴」の「統合できそうな項目」に、似た見出し語のペアが出ます（Q&Aが多いほうが残ります）。
- 元に戻せません（確認が出ます）。別名は、項目の「編集」で足したり消したりできます。

## 2c. つなぐ（Obsidian風）

- 本文（自分の理解・回答・判断）に `[[見出し語]]` と書くと、その項目へのリンクになります。`[[見出し語|表示名]]` も可。
- 青＝項目あり、点線＝まだ無い（押すと作れます）。
- 項目を開くと、**この項目へリンクしている項目（被リンク）**と、まだ無いリンクの一覧が出ます。
- 入力欄の 🔗 で、既存の見出し語を選んで挿入できます。
- 項目の **種類**（用語／手順／考え方）を選べます。手順は「自分の理解」に番号つきで書き、各ステップを `[[…]]` で用語につなぐと使いやすいです。
- 🕸 **つながり図**：全体、または1項目から2段階先まで。丸を押すと開きます。色は理解度。

## 3. 探す

検索欄に語を入れます。
- 空白で区切ると、**すべて含む**項目だけに絞り込みます（`API エラー`）。
- 見出し語・タグに当たった項目が上に出ます。一言・関連用語・自分の理解・Q&Aの中も探します。
- 全角・半角、大文字・小文字は区別しません。
- 回答の中だけに語があるときは、一覧にその周辺が出ます（💬）。

絞り込み：**未理解／理解中／理解済**。「分からなかったこと」を見返すときは「未理解」を使います。

## 4. 項目を読む

一覧の項目をタップすると、読む画面が開きます。
- 一言説明、**理解度**（タップで変更）、タグ、関連用語
- 関連用語の 📖 は、辞書に項目があることを示します。タップで開きます。
- **自分の理解**（編集で書く、自分の言葉のメモ）
- Q&A の一覧（タップで開く）：質問・回答・自分の判断・元の会話へのリンク
- **📋 再質問用にコピー**：この項目の質問・回答・自分の判断・自分の理解をまとめて、AIに続きを聞くための文をコピーします。AIに貼って、最後の「今回の質問」の続きを書いてください。
- 関連する項目（同じタグ）

### 結論・経過・理解（v0.9.0）

- **一覧のカード**に、❓何を調べていたか（問い）と 🎯結論 が出ます。結論の横の小さな文字が出どころです：自分の結論 / AIのまとめ / 自分の判断 / 自動抜粋（回答の要点。AIなし）。
- **「結論一覧」**ボタンで、1項目1行の一覧に切り替えられます（選んだ表示は覚えています）。
- **項目画面の上のまとめ箱**：❓何を調べていたか／🎯結論／🧭経過（Q&Aを古い順に、各回の要点）／❔まだ分からないこと／💡やさしく言うと。
- **📝 AIでまとめる**：問い・結論・経過・未解決・やさしい説明をAIが作ります（トークンを使います）。Q&Aを足すと「古い」扱いになり、自動抜粋や自分の判断に戻ります。
- **✏️ 結論を自分で書く**：自分の結論が最優先で表示されます。AIが上書きすることはありません。
- **📥 自分の理解に入れる**：やさしい説明を、確認したうえで自分の理解欄に追記します。
- **📚 体系・学習 の ③ 結論をまとめる**：まだの項目を3件ずつまとめて処理します（確認時にAPI回数を表示）。
- 書庫の棚・体系の木の各行にも結論が出ます。

## 5. quick-ref から移す

**クラウド経由（おすすめ）：** ⚙︎ →「☁️ quick-ref から取り込む」。quick-ref が同期しているクラウドから、AI Q&Aだけを直接読みます（読むだけで、quick-ref は変わりません）。「起動時に自動で取り込む」をオンにすると、開くたびに新しい分が入ります。同じエンドポイント・同期トークンを使います。

**ファイル経由：**

1. quick-ref の **JSONエクスポート** で書き出す。
2. 知識辞書の **⚙︎ → quick-ref の書き出しJSONを選ぶ**。
3. 「AI Q&A」のメモだけが入ります（保護メモ・ふつうのメモは入りません）。
4. 題名がそのまま見出し語になります。同じ題名は、1つの項目にまとまります。
   あとで項目の見出し語を直すか、Q&A を「編集」して見出し語を変えると、まとめ直せます。
5. 同じファイルを何度選んでも、重複しません。

## 6. バックアップ

**⚙︎ → 書き出す** で、JSONファイルが保存されます（ファイルアプリや iCloud Drive へ）。
- Q&Aが3件以上たまって1週間バックアップしていないと、一覧の上に知らせが出ます。
- 戻すときは **読み込む**。新しい端末にもそのまま読み込めます。
- 読み込みは、新しいほうが勝つ形で統合します（消えるものはありません）。

## 6b. 端末どうしの同期

⚙︎ の「端末どうしの同期」。両端末に同じ エンドポイント・同期トークン を入れ、片方ずつ「今すぐ同期」。以後は自動です。

## 6c. 暗号化と秘密の確認（v0.10.0）

**同期の暗号化**（設定 → 端末どうしの同期 → 🔒）
- 1台目：パスフレーズ（10文字以上）を2回入れて「🔒 暗号化を始める／変える」。以後クラウドには暗号化したデータだけが送られます（AES-256-GCM／PBKDF2 60万回）。すでにある平文のクラウドデータも、暗号化して置き換わります。
- 2台目以降：同じエンドポイント・トークンを入れ、パスフレーズを入れて「🔑 他の端末と同じパスフレーズを入れる」。以後は入力不要です（鍵はその端末にだけ保存）。
- パスフレーズを変えると、他の端末は「入れ直してください」と案内が出て、送信は止まります（データは壊しません）。
- **パスフレーズを忘れると、クラウドのデータは誰にも開けません。** 端末の中のデータは残るので、1台でパスフレーズを決め直せば再開できます。
- 暗号化しているのは同期データです。端末の中（IndexedDB）は暗号化していません。

**暗号化して書き出す／読み込む**（設定 → データ）
- パスフレーズを2回入れて「🔒 暗号化して書き出す」→ `…暗号化.json`。
- 読み込むときは、先にパスフレーズ欄へ入れてから「📥 読み込む」でそのファイルを選びます。

**秘密の確認**
- Q&Aを保存するとき、パスワード・トークン・鍵のような行があると、確認画面が出ます。「伏せ字にして保存」「そのまま保存」を選べます（画面には秘密そのものを出しません）。
- 設定の「🔍 秘密らしき文字を探す」で、保存済みの内容も調べ、まとめて〔伏せ字〕にできます（元に戻せません。先にバックアップを）。
- 判定は目安です。普通の長い英数字を拾うこともあります。

## 6d. 辞書パック（v0.11.0）

PC で作った **dict-pack.json**（コード・コマンド・用語の参考辞書）を読み込むと、**AI もトークンも使わずに**、端末の中で引けます。自分のQ&Aとは別に保管されます。

**入れ方**：設定 → 「📦 パックを読み込む」→ dict-pack.json を選ぶ（iPhone は「ファイル」アプリから）。同じファイルを選び直すと、新しい項目だけ入れ替わります。パックは同期されず、書き出しにも入りません（端末ごとに読み込みます）。

**引く**
- 一覧の検索欄に語を入れると、自分の項目の下に「📦 辞書パックでも見つかりました」が出ます。
- 一覧の上の「📦 辞書パック」バー、または設定の「🔎 開く」で、パック専用の画面が開きます。言語（JavaScript・PowerShell など）と、✅確認済み／⚠要確認／⏳変わりやすい／⭐覚えたい で絞れます。
- 語は空白で区切ると、すべて含むものが上に出ます。少ないときは「語の一部だけ一致」も足して出します。英語名（splice）でも、日本語の説明（配列 差し替え）でも引けます。

**項目の画面**：形 → 部品の意味 → 例 → よくある間違い の順。形と例は「コピー」で、そのまま貼れます。関連の項目へ移れます（パックにない関連は、リンクにしません）。
- 印：✅=例を実行（または構文検査）して確かめた／⚠=確信が低い／⏳=変わりやすい（最新を確かめる）。
- 「📌 自分の辞書に取り込む」：その内容を自分のQ&Aとして残します（復習・つながり・同期に乗ります）。
- 「☆ 覚えたい」：🎓復習に入れます。分かった→3日後→7日→14日→30日。あやしい→明日。忘れた→今日もう一度。
- 「📋 AIに渡す用にコピー」：形・例・よくある間違いをまとめてコピーします。

**自分の辞書とのつながり**
- 自分の項目の画面に、同じ名前のパック項目が「📦 辞書パックにも載っています」と出ます。
- 🧠 辞書に聞くでは、関係するパック項目（最大4件）も材料に加えます。自分の項目と食い違うときは、自分の項目を優先する指示をつけています。AIの答えの根拠に、📦が並びます。

## 6e. コードを作る（v0.12.0）

「引くだけでは絞り込めない」ときのために、**作りたいことから、使う部品を絞り込み、コードにする**流れを入れました。一覧の上の「🛠 コードを作る」から開きます。

1. **作りたいこと**を日本語で書き、言語を選ぶ（「おまかせ」なら言葉から判断します）。
2. **① 使う部品を絞り込む**（AIなし・無料）：辞書パック＋自分の辞書から、関係する部品を候補に出します。チェックで外す、「見る」で中身を確認、足りなければ検索して足せます。「🧠 AIに絞ってもらう」は、候補の一覧だけを送る少量のトークンで、選び直します（足りない部品も教えてくれます）。
3. **② コードを作る（AI）**：選んだ部品の「形・例・よくある間違い」と、自分の辞書の判断・「私のルール」を材料に、コードを作ります。自分の判断は、パックより優先する指示つきです。「✍ AIなしで下書き」は、選んだ部品の例をつなげた下書きです。
4. 結果：コードだけをコピーできます。JavaScript は構文を検査します（実行はしません）。
5. 「動いた／動かなかった」とメモを付けて「📌 辞書に残す」と、手順として残り、次からの材料になります（使った部品はタグ・関連に入ります）。

- 「私のルール」（毎回AIに渡す決まり）は、書き換えて覚えられます。
- 秘密らしい行は、AIに送りません。AIに送るのは、②と「AIに絞ってもらう」のときだけです。

## 7. 困ったとき

| 症状 | 試すこと |
|---|---|
| 貼り付けボタンが効かない | 欄を長押しして貼り付ける |
| 前に入れたデータが無い | Safariのタブと、ホーム画面のアプリは保存領域が別。入れた側で開く |
| AI整理が失敗する | ⚙︎ の「接続テスト」で原因を見る。AIは Gemini がおすすめ |
| 同期で「トークンが違います」 | 同期トークンを入れ直す（Worker の AUTH_TOKEN と同じ値。前後に空白や全角が入らないように） |
| 同期で「送信失敗（404/400）」 | sync-worker が `/sync/knowledge-dictionary` を受け付けていない。置き場を足す |
| 画面が古い | ホーム画面のアプリを完全に閉じて開き直す（オンラインで開けば更新されます） |
| 「この環境では保存できません」 | プライベートブラウズでは保存できません。通常のタブか、ホーム画面のアプリで開く |
| 保存したはずが消えた | まず「読み込む」でバックアップを戻す。今後はこまめに書き出す |
